# MeldShard

MeldShard is a distributed system enabling scalable, auto-scaling architectures through dynamic data-replication and processor management.

MeldShard is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/MeldShard.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure MeldShard, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
